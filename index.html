About Us

Q+ Lab is a research collective founded in 2026 to empower queer women in AI — opening doors to meaningful research, mentorship, and recognition in a field where our voices remain underrepresented.

Here, members learn AI together, build projects that span reinforcement learning, agents, benchmarks, and finance, and create impact through research, competitions, and open-source work — because the future of AI should be shaped by every voice.

Projects

Four projects, four corners of AI — each tackling an open problem the field cares about, and each released openly so others can build on it.

OpenRA-RL

Reinforcement learning environment for real-time strategy · built on OpenEnv

An open RL environment that turns the classic RTS game OpenRA into a playground for LLM agents. Agents must perceive the battlefield, plan, and act under complex spatial reasoning — a challenge far beyond board games like Go or chess.

Under review · ICLR 2027 OpenEnv Challenge
HF Blog Competition Blog HF Space GitHub Replay ▶

TraderBench

Finance agent benchmark · UC Berkeley AgentX–AgentBeats Competition

A benchmark for evaluating how robust LLM agents are in adversarial capital markets. Our team AgentBusters placed second in the Finance Agent track of UC Berkeley RDI's AgentX–AgentBeats Competition.

2nd Place · Finance Agent Track arXiv 2026
Paper GitHub Leaderboard

Agent Safety · QuietChaos

Red-teaming LLM agents · UC Berkeley AgentX–AgentBeats Competition

Team QuietChaos designed attacker agents that probe the defenses of LLM agents across realistic scenarios, and stress-tested the approach on 25+ open and frontier models.

[Award TBD] AgentX–AgentBeats 2026
GitHub

OpenRA-Bench

Scenario-based spatial reasoning benchmark

Hand-designed RTS scenarios, each with a defined start state, goal state, and algorithmic baseline. Instead of asking whether an LLM can play, we pinpoint exactly where models break down — seeing, planning, and executing.
